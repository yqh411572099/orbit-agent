# Orbit Agent · 多目标长期陪伴管家

一个基于大模型的个人事务管家。你在一个总入口里和它聊天，随时把"考研、考证、孕期、减重……"这类需要长期跟进的事丢给它；它会为每件事开一个独立的专属对话，持续记住关键信息、按时间推进计划、到点主动提醒。

它要解决的，是大模型在长期事务上的三个老问题：**记不住**、**多件事之间互相串味**、**聊完给个计划就再无下文**。

## 它怎么用

- **主对话**：全局总入口，闲聊、创建目标、跨事项复盘，看得到你所有的事。
- **子对话**：每个长期目标一个专属对话，天然互不干扰，只关注这一件事，独立跟进待办与提醒。
- 你可以像和人聊天一样汇报进展、改时间、问问题；也可以点"创建新目标"填表发起。关键变更（改日期、加关注项、记录数据）会先弹确认卡，你点头才生效。

## 核心思想

- **一个大脑，外设可插拔**。大模型只负责"想"，联网、地图、知识库、计算、待办、记忆库都是它随时取用的外部能力，像人用笔记本和工具一样。能力以大类方式按需呈现，不一次堆满上下文；新增能力像插插件一样接进来。
- **感知—记忆—行动围绕模型组织**。每句话先理解"说的是哪天、哪件事、哪个人"，再决定它影响哪两类东西——你的**目标/时间轴**，以及你的**长期记忆**；最后由行动层负责到点提醒、定时推进。
- **聊天是流水，记忆是沉淀**。原始对话只归档不直接当记忆；系统周期性把有长期价值的信息提炼成结构化记忆，自动识别冲突与过期内容。记忆默认全局可见，专属对话按相关性被授权访问，既隔离又能共享。
- **时间轴驱动，而非一次性计划**。目标被拆成随时间演进、可随你反馈重排的待办，到点主动提醒，而不是聊完甩给你一张静态计划表。
- **确定性的事不赌模型**。数字和日期计算、时间节点判断交给确定的工具/规则，模型不心算，结果可复现；定制逻辑只留在真正因场景而异的地方，其余全部走通用链路，新场景以独立"域"热插拔接入。

## 能力一览

- **长期记忆**：周期性提炼、结构化沉淀、冲突与过期治理，主/子对话按需隔离共享。
- **时间轴与待办**：按关注项分组、周期提醒、历史折叠、点击完成；关键日期变更自动重排；到点可结合近况生成当下这条提醒。
- **多场景内置**：孕期管家（孕周/产检/建档等时间轴、准爸爸准妈妈视角、地区政策与周边）、考研、证书备考（建前联网调研、资料链接），以及不限定类型的通用计划。
- **外部信息**：联网搜索、地图/周边检索、可沉淀复用的内部知识库；浏览器定位；可按对话独立开关这些按量计费的外部能力。
- **数据可视化**：模型为目标声明值得追踪的指标，你日常汇报即记录，头部卡片 + 图表展示趋势。
- **其他**：语音输入与播报、思考过程折叠展示、账号体系、对话历史增量同步与分页加载。

## 技术栈

Java 21、Spring Boot 3、Spring AI（火山方舟），DDD 分层 + 端口适配器（存储、模型、向量库均可替换），内置 H2 与 Milvus 向量库，原生单页前端（流式输出 + 图表，无前端工程依赖）。

## 快速开始

```bash
# 需要 JDK 21、Maven；模型 key 通过环境变量 ARK_API_KEY 提供
mvn -DskipTests package
java -jar target/butler-1.0.1.jar
# 打开 http://localhost:8080/
```

也可用脚本在固定终端窗口一键启动（含向量库）：`scripts/start_all.sh`；仅重启后端：`scripts/start_butler_window.sh`。
