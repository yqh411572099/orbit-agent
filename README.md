# AI-Butler · 多目标长期生命周期智能管家 Agent

一款基于大模型的个人事务管家：在**一个全局主对话**下创建并**并行管理多个长期目标**（孕期管家、考研、考证、减重/通用计划等）。Agent 持续跟进每个目标、沉淀长期记忆、按时间轴主动提醒，解决大模型在长期事务中"记不住、多目标串味、计划不随时间推进"的问题。

- **主对话（全局总入口）**：闲聊、创建目标、全局查询、跨事项复盘；默认可见全部记忆。
- **子对话（单一目标专属）**：每个目标一个独立会话，天然上下文隔离，只读取与本目标绑定的记忆，独立跟进待办与提醒。

技术栈：Java 21 · Spring Boot 3 · Spring AI（Alibaba/火山方舟）· DDD 分层 + 端口适配器 · H2（可替换）· 向量库 Milvus（知识库）· 原生前端（SSE 流式 + SVG 图表，无外部前端依赖）。

## 核心能力

**认知架构（感知—记忆—行动，围绕模型组织）**
- 统一认知循环只有一套：接收消息 → 意图/事件推理 → 影响「目标/时间轴」与「记忆」两个面 → 流式回复。
- 场景以独立域（`ScenarioDomain` Bean）热插拔，新增目标类型不改主链路；场景只改"知道什么、关心什么、有哪些工具"，不改思考方式。

**长期记忆（区分原始对话与提炼记忆）**
- 原始聊天仅归档，不直接作为记忆；每 2 小时增量提炼，过滤闲聊、只沉淀有长期价值的结构化信息。
- 中立记忆库 `user_memory` + 多对多关联表 `memory_session_rel`：记忆默认主对话可见，子对话按 LLM 关联判定按需授权；提炼时回灌已有记忆做冲突/过期治理。
- 结构化属性 `Attribute`：公共精简字段 + 各域自定义子类，LLM 可追加未定义字段（extras 透传）。

**目标与时间轴（替代一次性计划输出）**
- 目标可由确定性时间轴（域模板，如孕期孕周节点）驱动，或由 LLM 动态生成待办；关键日期变更后自动重排。
- 待办按关注项分组、周期任务（每天/每周）、提醒时刻、历史折叠、点击完成、过期不默认完成而待确认。
- 建目标前可先联网调研（如考证报名/资料），方案确认后才创建。

**主动触达与行动层**
- 定时提醒到点把待办推进到子对话；任务可带 `aiBrief`，到点由 LLM 结合近期对话**动态生成本次推送**（如每日食谱/训练），模型异常自动降级为静态提醒，提醒链路不依赖模型可用性。

**可视化指标卡（模型决定展示什么、用什么图）**
- 模型为目标声明可量化指标（`metricDefs`：key/名称/单位/图表类型），用户汇报数值时抽取数据点（`metricPoints`）。
- 子对话头部展示指标卡（如当前体重），点击展开 SVG 折线/柱状/饼图，按日累积成趋势；单位跟随用户口径，不做硬编码换算。

**工具体系（分层加载，不一次性塞全部工具）**
- 工具按大类组织（计算器 Calculator、联网搜索 WebSearch、知识库 KnowledgeBase、地图/地理检索 GeoSearch 等），模型按信息可靠性自主选择；工具结果优先于模型猜测。
- 大类 → 子工具两级暴露，渐进式披露，避免一次性把全部工具塞进上下文；工具可插拔注册、自带单元测试。
- 确定性计算从模型心算中剥离：`math_calc`（加减乘除）与 `calendar_calc`（日期差/推算/星期几），凡工具支持的数字/日期结果一律走工具、不正文心算。
- 周边检索先定位"以哪里为中心"再正向地理编码检索；浏览器定位 + 高德 POI。
- 高价值联网信息可经用户确认后向量化沉淀进 Milvus 知识库，可溯源复用。

**上下文锚定（感知层先消解时间/指代）**
- 回答/记账前先把"今天/昨天/春节/附近"等相对时间与指代消解为绝对日期、主体、对象，锚定器可调用全部工具查实，结果注入正文与事件抽取，避免跨日串数据、时间口径错乱。

**外部计费工具开关（按会话）**
- 每个主/子对话可独立开关按量计费的外部工具（WebSearch 联网、GeoSearch 地图）；关闭后这些工具不注册给模型（适合未续费/不用外部服务），本地知识库与计算工具不受影响。开关只能由界面按钮配置，对话内容无权修改。

**其他**
- 账号体系（普通/测试用户）、服务端压缩 session 鉴权；真实用户删除走归档表、测试数据硬删。
- 差异同步：前端轮询按更新点带版本游标，只拉变化部分；对话首屏 20 条、向上加载更早。
- 语音输入/播报（火山引擎流式 ASR/TTS）、思考过程折叠展示、确认弹窗（改前预览字段/关注项/待办/指标卡变更）。

## 当前内置场景

| 场景 | type | 特点 |
| --- | --- | --- |
| 孕期管家 | `pregnancy` | 预产期→孕周处境摘要、产检/建档/生产/产后确定性时间轴、关注项依赖、男方/女方视角、地区政策与 POI |
| 考研备考 | `exam_prep` | 考试日→复习阶段、时间轴与资料链接 |
| 证书备考 | `cert_prep` | 建前联网调研（报名/教材/查分入口）、考点城市、资料链接栏 |
| 通用计划 | `generic` | 无预设模板，模型按诉求分析参数、关注项与待办（减重、旅行、学技能等） |

## 本地运行

```bash
# 需要 JDK 21、Maven；模型 key 通过环境变量 ARK_API_KEY 提供（~/.butler.env）
mvn -DskipTests package
java -jar target/butler-1.0.1.jar
# 打开 http://localhost:8080/
```

一键在固定 Terminal 窗口启动（含 Milvus Lite）：`scripts/start_all.sh`；仅重启后端：`scripts/start_butler_window.sh`。
